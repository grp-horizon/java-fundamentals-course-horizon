# Fundamentos de Java para principiantes con Chispa

Curso en video de aproximadamente una hora (6 lecciones) para estudiantes de 12 a 17 años sin experiencia previa. Aprendes Java y los conceptos básicos de la programación orientada a objetos con una mascota virtual, Chispa.

**No hay que instalar nada:** todo se hace en el navegador (Chrome, Firefox, Safari o Edge), con un editor en línea gratuito y sin cuenta.

- **Lista de reproducción** (videos no listados): https://www.youtube.com/playlist?list=PLNl8iMMYTKQc
- **Plan del curso:** [plan-del-curso.md](plan-del-curso.md) (resumen, lecciones con sus enlaces, prácticas y equipo)
- **Código de las lecciones:** este repositorio

## Cómo usar este repositorio

1. Mira el video de la lección.
2. Cuando aparezca la escena «Pausa el video y practica», abre el enlace de la práctica en la tabla de abajo: se abre un editor en línea (OnlineGDB) con el programa ya escrito. No necesitas cuenta.
3. Pulsa **Run** para ejecutarlo y cambia el código según la consigna.
4. Si quieres comparar con una solución, abre su carpeta en `completed-examples`.

## Estructura del repositorio

```
plan-del-curso.md     el plan del curso: resumen, secuencia de lecciones con enlaces de YouTube y de los editores
starter-files/        el programa de inicio de cada práctica, tal como sale en el video
  leccion-N/bloque-M-<tema>/Main.java, PRACTICA.md, salida-esperada.txt
completed-examples/   la práctica ya resuelta
  leccion-N/bloque-M-<tema>/Main.java, salida-esperada.txt
scripts/              verificar.mjs: compila y ejecuta todos los ejemplos
```

Cada ejemplo es un solo archivo `Main.java`: se puede pegar tal cual en un editor en línea. Si el programa pide datos, la carpeta trae un `entrada.txt` con un ejemplo de lo que hay que escribir.

## Ejecutar los ejemplos en tu computadora (opcional)

Solo hace falta si quieres comprobar los ejemplos fuera del navegador: JDK 21 y Node.js 20 o superior.

```
node scripts/verificar.mjs
node scripts/verificar.mjs leccion-3
```

El script compila cada `Main.java`, lo ejecuta con su `entrada.txt` (si existe) y compara la salida con `salida-esperada.txt`.
