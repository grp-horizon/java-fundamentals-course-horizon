# scripts

`verificar.mjs` compila y ejecuta cada `Main.java` de `starter-files` y `completed-examples`, y compara su salida con `salida-esperada.txt`.

Requisitos: JDK 21 y Node.js 20 o superior. Desde la raíz del repositorio:

```
node scripts/verificar.mjs
node scripts/verificar.mjs leccion-3
```
